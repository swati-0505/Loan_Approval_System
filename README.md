# 🏦 Loan Approval Prediction System

## 📌 Overview
A machine learning–based classification system that predicts loan approval outcomes using applicant financial and demographic data & Compares multiple ML algorithms to find the best performing model.

## 🎯 Problem Statement
Manual loan processing is time-consuming and inconsistent. This system automates approval decisions using historical applicant data and 
ML classification algorithms.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook

## 📊 Project Workflow
1. Data Loading & Exploration
2. Exploratory Data Analysis (EDA)
3. Data Preprocessing & Cleaning
4. Feature Engineering
5. Model Building & Training
6. Model Evaluation & Comparison
7. Final Prediction

## 🤖 ML Algorithms Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
